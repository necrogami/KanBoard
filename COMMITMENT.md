# Commitment

KanBoard is free software and will stay that way. These are promises to
everyone who self-hosts it, contributes to it, or builds on its API and
MCP server.

1. **No tiers.** There is no Pro, Enterprise, Cloud-only, or Community
   edition. There is one KanBoard, and it is this repository.

2. **Nothing shipped is ever taken away.** A feature that appears in a
   release is never removed or moved behind payment, registration, or a
   separate download in a later release. If a feature must be replaced,
   the replacement ships first and the old one is deprecated with a
   documented migration path.

3. **Your data is always yours.** A complete, documented, versioned export
   of everything is available to project administrators in every release,
   from the web UI, the API, and the command line.

4. **No telemetry.** KanBoard sends nothing anywhere unless you configure
   it to (for example, a webhook you create). There is no phone-home, no
   usage reporting, no license check.

5. **AGPL-3.0-only, forever.** Contributions are accepted under the
   Developer Certificate of Origin. There is no contributor license
   agreement, so no one, including the maintainers, can relicense the
   contributed code.

6. **Identity is infrastructure, not an upsell.** Single sign-on
   (OpenID Connect and friends) is part of the core and always will be.

These commitments are part of the product. A change to this file is a
breaking change and is treated as one.
